# Cheffito · Servidor da loja (instaladores)

Este repositório guarda apenas os instaladores do servidor da loja do Cheffito para Windows, publicados como *Releases*. O servidor instalado consulta a release mais recente para avisar quando há uma versão nova.

Cada release traz o instalador (.exe) e o arquivo .sha256 para conferir o download.

Não há código-fonte aqui.
